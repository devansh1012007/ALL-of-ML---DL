## 3. Root cause

Display honesty, not parsing. The honesty invariant "seconds is null unless
both timestamps parse" was satisfied for NaN (unparseable) but not for
negative: a negative diff *parses* yet is not a trustworthy duration (clock
skew, NTP step, corrupt rows, or wire drift). `Math.max(0, …)` — written as
sub-second rounding defense — silently normalizes the data-integrity failure
to a plausible false value (0), indistinguishable from a genuine instant
run. The chip's `seconds !== null` gate therefore cannot distinguish
"unknown/negative" from "true zero".

## 4. Approach chosen and why

Option A from INV-negative-counts §N1 (mission A-010 hide-chip default):
extend the null sentinel to include negative diffs — silence is the
established "unknown" convention from P3 (f292a9c), the user cannot repair
server timestamps from Run Details, and a false "0 s" is strictly worse than
silence. `Math.max(0,·)` is kept as redundant defense-in-depth (removing it
in the same change would be churn).

Alternatives rejected (per investigation §N1, re-affirmed):
- Warn chip — invents UX/copy needing content-owner approval; needs
  threshold + screen-reader semantics; disproportionate.
- Show negative / remove clamp ("Took -60 s") — impossible physics.
- `wall_seconds` — product change (different semantics, null for
  queued/interrupted runs, integer column), not a bug fix.

This fixes the cause: the computed duration is now null (unknown) instead of
a fabricated 0, so no false assertion is rendered.

## 9. Edge cases and abuse scenarios

Handled (and where):
- `finished < started` (any magnitude, no threshold) → hidden
  (`durationMs < 0` in RunDetails.jsx:220).
- Mixed garbage/valid → NaN → hidden (pre-existing `Number.isNaN`).
- `started == finished` → renders `"Took 0 s"` (falsiness not used).
- Missing/null one side → `durationMs === null` → hidden (pre-existing).

Consciously not handled (why):
- Sub-millisecond negative vs positive rounding: irrelevant — any negative
  hides, any non-negative rounds via existing `Math.max`.
- `wall_seconds` display, warn copy, backend clock repair: product
  decisions out of scope.

Unknown: whether production rows actually contain negative diffs
(requires DB access, not done).
