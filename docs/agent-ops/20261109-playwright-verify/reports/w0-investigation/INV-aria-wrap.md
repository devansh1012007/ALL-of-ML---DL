The row has `flex-wrap: wrap` so the copy button drops, but flex-item min-content still needs the text to be breakable + the item shrinkable.
- **Root cause chain:** T-303 fixed button squeeze (row wraps) but not text min-content: an unbreakable flex item whose min-content exceeds the container overflows regardless of `flex-wrap`. Two latent gaps: (1) no break opportunity on the code text; (2) wrapper `<div>` at AdminScreen.jsx:555 is a flex item with default `min-width: auto` → min-content, so even with (1) fixed the wrap cannot shrink below the token's min-content without `min-width: 0` (precedent: `.model-name` pairs both [VERIFIED styles.css:167]).
- **Blast radius:** styles.css `.admin-invite-code` family; AdminScreen.jsx:555-556 only. No token/color change, no layout-height change for short codes.
- **Fix options:**
  - A (recommended): add `.admin-invite-code-text { min-width: 0; overflow-wrap: anywhere; }` in styles.css (next to :310) and `className="text-sm tabular-nums text-accent admin-invite-code-text"` on AdminScreen.jsx:556; ALSO add `min-w-0` (or a `min-width:0` class) to the wrapper div at :555 — one of the two must shrink; cheapest is `className="min-w-0"` on :555. `overflow-wrap: anywhere` over `word-break: break-all`: anywhere only breaks when the line must break (respects the container), break-all breaks at every character capriciously (choppier, uglier mid-token splits in narrow-but-not-overflow cases). Codebase precedent is unanimous: two `anywhere`, zero `break-all` [RAN grep]. Safe default even if shape were [UNKNOWN] — and shape is verified.
  - B: `overflow-wrap: anywhere` on `.admin-invite-code` itself (property is inherited, so it reaches the text) + `min-width:0` via a child selector — fewer JSX edits but vaguer ownership; acceptable fallback.
  - C: `word-break: break-all` on the code div — rejected (see A; not codebase-consistent; harsher splits).
- **Test plan:**
  - Static pin (static.test.js, extend T-303 describe): assert `/\.admin-invite-code-text\s*\{[^}]*overflow-wrap:\s*anywhere/` and `/\.admin-invite-code-text\s*\{[^}]*min-width:\s*0/`, plus AdminScreen.jsx contains `admin-invite-code-text`; self-check: pre-fix rule fails the pin (pattern-test the old literal as in static.test.js:600-601).
